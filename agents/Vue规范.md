# Vue 规范

## 单文件组件

- Vue 组件统一使用 Vue 3 Composition API 和 `<script setup lang="ts">`。
- 单文件组件顺序固定为 `<script>`、`<template>`、`<style>`。
- `<template>` 只能保留一个根节点，不允许多个并列根标签或组件。
- 页面结构、文本和原生标签的使用遵循 [HTML 规范](./HTML规范.md)；组件标签使用 PascalCase。
- Props 只读，不在子组件中直接修改；双向绑定使用 `defineModel`。
- 自定义事件在脚本类型和模板监听中统一使用 kebab-case，例如 `tab-change`。
- 变量名与属性名一致时使用绑定简写 `:xxx`；布尔属性为 `true` 时直接写属性名。
- 不在模板表达式中使用 `as` 类型断言，也不调用会修改状态、发请求或产生其他副作用的函数。
- 过滤、排序和复杂 class 判断优先放入计算属性，保持模板只负责声明视图关系。

## 组件组织

- 组件单独建立目录并使用 `index.vue` 作为入口。
- 组件具有独立业务职责、可复用交互、复杂状态或明显降低父文件复杂度时，应拆成子组件；不要把每个简单 DOM 块机械拆分。
- 只在当前页面或组件使用的子组件放在其同级 `components` 目录，不提升到全局目录。
- 具备跨页面复用价值的组件放在 `src/components`；同类组件较多时可按职责继续分组。
- 循环列表项包含独立展示逻辑、交互或较多模板内容时，抽成列表项组件；仅有少量静态标签时可以保留在父组件。
- 页面功能模块较多时按业务区块拆分，避免单文件承担互不相关的职责。
- 可独立复用或测试的复杂组合式逻辑拆入一个或多个 `useXxx` Hook；纯计算且不依赖 Vue 响应式能力的逻辑放入工具函数。
- Vue 文件内样式超过 100 行时再抽离到同目录 `index.less`，并从 `<style scoped lang="less">` 引入。

## 响应式与组件通信

- 基本状态使用 `ref`；对象或数组需要显式约束时使用 `ref<Type>()` 泛型写法。
- 派生状态使用 `computed`，不要通过 `watchEffect` 修改另一份可计算得到的状态。
- `watch` 和 `watchEffect` 只处理响应式副作用；监听对象属性时使用 getter，避免意外丢失响应性。
- 子组件优先通过 Props 接收数据、通过 Emits 通知父组件，不依赖组件实例直接修改子组件内部状态。
- 模板引用按实际对象使用 `HTMLElement` 或 `InstanceType<typeof Component>`，并正确处理挂载前的空值。
- 列表渲染必须提供稳定且唯一的 `key`；不要把 `v-if` 和 `v-for` 放在同一元素上。

## Props、Emits 与 Model

- Props、Emits 和 Model 使用类型声明方式，格式遵循 [Vue 文件代码排版](./Vue文件代码排版.md)。
- 仅供模板使用的 Props 直接调用 `defineProps<Props>()`；脚本需要访问时才声明 `$props`。
- Emits 的负载必须具有明确类型，不使用无参数约束的字符串数组。
- Model 名称使用 camelCase，模板属性由 Vue 自动映射为 kebab-case。

## 样式与文案

- 组件样式默认使用 `<style scoped lang="less">`，全局基础样式仅放在项目既有全局样式目录。
- 用户可见文案默认使用简体中文；设计稿或国际化资源明确指定其他语言时遵循其约束。
- Template 模块注释、Less 嵌套和动画分别遵循 [注释规范](./注释规范.md) 与 [CSS 规范](./CSS规范.md)。
